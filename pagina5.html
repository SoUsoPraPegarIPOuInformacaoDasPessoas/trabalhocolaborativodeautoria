Como o site foi desenvolvido?

Eu desenvolvi o site utilizando HTML e CSS. O HTML foi usado para criar a estrutura e organizar os textos, títulos, botões e seções do site. Já o CSS foi utilizado para personalizar o visual, com as cores, os efeitos, o layout e a adaptação para celulares. Os textos foram desenvolvidos pelo integrante Sherman Vinícius Gonçalves e as Imagens foram conquistadas pelo Leonardo Mondoni Chaves; Site criado por Matheus Henrique da Silva Maximo
